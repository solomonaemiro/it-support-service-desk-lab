#Ticket #506980 — Amharic Keyboard Layout Setup

##Incident Summary

The user reported that they were unable to type using a secondary language and could not switch between keyboard input layouts.

The requested secondary language was Amharic.

The incident was investigated as a Windows language and keyboard configuration issue.

Status: Open
Priority: Normal
Department: Support
Source: Web

![Ticket #506980](../images/61%20%235%20Ticket%20Created.png)

*Ticket #506980 showing the reported Amharic keyboard configuration request.*

---

###Initial Assessment

The workstation's existing keyboard configuration did not provide the required Amharic input option.

The troubleshooting focused on:

- Checking the installed Windows language configuration.
- Adding Amharic as a language.
- Installing the required language components.
- Configuring the keyboard input method.
- Verifying that the user could switch between keyboard layouts.

---

###Step 1 — Open Language Settings

Windows Settings was opened and the following path was used:

Settings → Time & Language → Language & Region

The installed languages and available language options were reviewed.

![Language settings before configuration](../images/62%20%235%20Languages%20before.png)

*Windows language configuration before the Amharic input language was added.*

---

###Step 2 — Add Amharic

The Add a language option was selected.

Amharic was searched for and selected from the available language options.

The required language components were then installed.



---

###Step 3 — Configure the Keyboard Layout

After Amharic was added, its language options were opened and the available keyboard/input configuration was reviewed.

The required keyboard layout was configured so that it could be selected from the Windows input language switcher.


---

###Step 4 — Verify Language Switching

The Windows input language switcher was used to change between the existing keyboard layout and Amharic.

The Amharic input option appeared in the available keyboard layouts.

The user could therefore switch between the configured input languages when required.

---

###Resolution

Amharic language support and the required keyboard input configuration were successfully added to the Windows workstation.

The user was able to switch between keyboard layouts and enter text using the Amharic input method.

No additional hardware or third-party software was required.

---

###Verification

The configuration was tested after installation.

Result:

- Amharic was available as an input language.
- The keyboard layout could be selected from the Windows input switcher.
- The user could switch between input languages.
- Amharic text could be entered successfully.
